# Factory OS — Enterprise AI Decision Intelligence Platform

Factory OS is a full-stack manufacturing intelligence platform that fuses real-time IoT telemetry, ML-based failure prediction, RAG knowledge retrieval, and a LangGraph-style multi-agent copilot into a single operations dashboard.

## Architecture

| Directory | Purpose |
| --------- | ------- |
| `backend/` | FastAPI v6 REST API (DB-backed), Celery workers + beat, ML prediction endpoints |
| `ai_service/` | Standalone ML service: model registry, failure classifier, RUL regressor, anomaly detector |
| `frontend/` | Next.js 16 + Tailwind v4 + Zustand dashboard (17 routes) |
| `scripts/` | Boot scripts: `init_models.py`, `seed_database.py` |
| `models/` | Serialized joblib ML models (generated by `init_models.py`) |
| `docs/` | API spec and database schema |

### Stack
- **Backend:** Python 3.11 · FastAPI · SQLAlchemy 2.0 (async) · Celery · Redis · PostgreSQL/SQLite
- **AI:** scikit-learn / XGBoost joblib models · ONNX exports · SHAP explainability
- **Frontend:** Next.js 16 · React 19 · Tailwind v4 · Zustand · Recharts

## Quick Start

### 1. Prerequisites
- Python 3.11+, Node 20+, and (optionally) Docker.

### 2. Install & bootstrap

```bash
pip install -r backend/requirements.txt
cd frontend && npm install && cd ..
npm install            # root (concurrently)

npm run init           # generates models/ + seeds the SQLite DB
```

### 3. Run all services

```bash
npm run dev            # backend :8000, AI :8001, frontend :3000 (via concurrently)
```

Or individually:

```bash
npm run dev:backend    # uvicorn on :8000
npm run dev:ai         # uvicorn on :8001
npm run dev:frontend   # next dev on :3000
```

### 4. Docker (full stack incl. PostgreSQL, Redis, Celery)

```bash
cp .env.example .env
npm run docker:up      # postgres, redis, backend, ai-service, celery-worker, celery-beat, frontend
```

## Data

The development environment uses a SQLite database (`factoryos.db` at repo root) created and seeded automatically. Production uses PostgreSQL (see `docker-compose.yml`). Re-seed anytime with `npm run init` (note: `seed_database.py` uses fixed GUIDs and is idempotent).

## Frontend Data Strategy

Every page loads from the live backend via `frontend/src/services/index.ts` (typed API client with JWT auth) and transparently falls back to `frontend/src/mock` fixtures when the backend is unreachable, so the UI remains fully navigable offline.
